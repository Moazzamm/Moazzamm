Mobbin Offline Saver

Save any Mobbin app's flows as one file that works without internet.

Save Mobbin page
  1. One time: show the bookmarks bar (Ctrl+Shift+B, Mac Cmd+Shift+B), then drag the button above onto it.
  2. Log in to Mobbin and open any app's Flows page.
  3. Click Save Mobbin page in your bookmarks bar, then leave the page alone until the file downloads.

If dragging doesn't work: create a bookmark by hand and paste the contents of bookmarklet.txt as its URL.
