## Claude playbook (from Matt's "Ultimate Beginner's Guide to Claude")

### 1. Prompting
- Good prompt = **context + task + format** (who I am / what I want / length, tone, structure).
- Refine by replying in the same chat ("shorter", "warmer tone") instead of starting over.
- Same prompt gives different results each time. That's normal.
- Models: Haiku = fast and light, Sonnet = everyday default, Opus/Fable = hardest tasks. Higher effort and bigger models use up the allowance faster.
- Usage limits refill on a schedule. Hitting one breaks nothing.

### 2. Files, search and research
- One task per chat; new topic, new chat. Pin the chats you use most.
- Upload PDFs, spreadsheets, screenshots and photos to get summaries, tables and feedback.
- Turn on web search for current information with sources. Use Research (paid) for a long, cited report.

### 3. Making things
- Ask for real files (Excel, Word, slides) or **artifacts**: live web pages, apps and quizzes shown next to the chat. Good for practicing UI ideas.

### 4. Memory
- **Projects**: add files and instructions once and every chat in the project uses them.
- Settings: personal instructions, memory, "search past chats" (turn it on), and importing memory from ChatGPT.
- Incognito chat = no memory.
- Phone and desktop apps sync everything (photo + voice questions on the go).

### 5. Connectors and skills
- Connectors link Claude to apps (Gmail, Drive, Calendar, Slack...). Claude asks before acting.
- Skills = reusable instruction "recipes" (Customize → Skills), e.g. Theme Factory for good-looking slides, frontend-design for web pages.

### 6. Hands-off work
- **Cowork** (paid): connect a folder and Claude organizes files and builds spreadsheets. Start with manual approval.
- **Scheduled tasks**: recurring jobs such as a weekly report.
- **Claude Design** turns a description into a UI mockup, and **Claude Code** turns the mockup into a working site or tool. Most relevant for my frontend/UX goals.
- Best move: have Claude Code build me a *tool* that does the repetitive job, so it runs without chatting.
