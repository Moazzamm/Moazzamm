# CLAUDE.md

## UI/UX work

For any UI/UX request (screens, flows, dashboards, onboarding, critiques, or
frontend UI code), use the `saas-ui-ux` skill in `.claude/skills/saas-ui-ux/`.
It holds the Mobbin + B2B SaaS pattern playbook: ground answers in patterns from
shipped products (Linear, Stripe, Attio, Notion, Vercel, …), name the precedent,
and cover every screen state.
